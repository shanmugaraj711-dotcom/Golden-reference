# Project Factory Unit Economics

The customer price is an outcome price, not a pass-through model subscription.

## Measure per project

- model inference cost
- compute cost for local inference
- storage
- build/test minutes
- browser/runtime verification
- deployment
- support allowance
- payment fees
- retry/rework cost

## Core metric

`contribution_margin = customer_price - variable_delivery_cost`

Track this by project type and package.

## ₹499 entry package

A ₹499 package should be deliberately bounded. It can cover a small, standardized build only after measured variable delivery cost is known.

Higher-complexity projects should consume higher packages or require a custom quote.

## Strategic target

External models are a temporary variable cost where they produce superior results. Local/self-hosted models should be introduced where their total cost of ownership is lower at our workload and quality remains acceptable.

The objective is not "zero AI cost." The objective is **high customer value, low variable delivery cost, predictable margin, and vendor independence**.
