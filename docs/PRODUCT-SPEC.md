# Project Factory — Product Specification

## Promise

**You describe it. We build it.**

A customer uses a phone or browser to describe a software project. The service converts the request into a scoped package, builds it through the Project Factory, verifies the result, and delivers the project/preview.

## First package principle

Start with a tightly scoped starter package rather than unlimited development. Price is configurable after measuring real inference and infrastructure costs.

## Customer should never need

- A coding environment
- Git knowledge
- An AI coding subscription
- An API key
- Local model installation
- Vercel configuration

## Factory acceptance

A project is not delivered because an agent says it is complete. Delivery requires acceptance criteria, test evidence, verification evidence, and a final checkpoint.

## Business metric

Track contribution margin per successful project:

`customer price - model/inference cost - execution/storage/deployment variable cost`

The goal is positive margin at the lowest practical package price.
