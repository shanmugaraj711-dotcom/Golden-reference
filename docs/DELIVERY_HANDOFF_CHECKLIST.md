# Delivery Handoff Checklist

## Transfer
- [ ] Customer destination repository explicitly authorized
- [ ] Customer hosting project explicitly authorized
- [ ] Generated artifact validated
- [ ] Deployment health check passed
- [ ] Source and deployment ownership transferred/confirmed
- [ ] Customer receives live URL and operating documentation

## Managed
- [ ] Managed repository selected
- [ ] Managed hosting project selected
- [ ] Deployment health check passed
- [ ] Maintenance scope and recurring fee recorded
- [ ] Customer receives live URL and support path

## Decide Later
- [ ] Temporary managed destination selected
- [ ] Deployment health check passed
- [ ] Ownership decision recorded before final handoff

## Never do
- Never deploy customer work into PromptStudio production by default.
- Never put customer secrets into generated source code.
- Never claim a deployment succeeded without a live health check.
