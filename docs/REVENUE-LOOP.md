# Revenue Loop

## Client track

`Lead → Intake → Scope → Quote → Payment → Build → Verify → Deliver → Feedback → Margin`

Client work is the fastest route to cash and real-world factory evidence.

## Product track

`Idea → Factory build → Launch → Users → Revenue → Improve → Repeat`

Own products create recurring/scalable value without requiring one new custom build for every rupee of revenue.

## Operating rule

Run both tracks. Client work should not permanently consume the capacity needed to improve owned products.

## Automation trigger

Do not automate a step merely because it exists. Automate when repeated work is measurable, error-prone, or materially time-consuming. Use the first customer projects to identify the bottlenecks.
